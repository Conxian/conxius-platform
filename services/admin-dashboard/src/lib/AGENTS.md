# Provider evidence guidance

Preserve independently owned provider boundaries and the Bitcoin-rooted universal-chain scope. Read `../../../../docs/architecture/PROVIDER_REGISTRATION_DISCOVERY_2026.md` when changing registration ingestion. Registration, health, qualified operations, and independent production acceptance are separate facts.

Keep diagnostic reads bounded, authenticated, no-store, redirect-free, and credential-safe. Missing/incompatible evidence remains unavailable; no SDK count or feature flag authorizes signing, custody, routing side effects, or deployment.
