# Governance Source of Truth

This directory (`.github-private` within the root orchestrator) is the canonical source for Conxian-Labs governance, policy, and strategy documents.

## 1. Canonical Files
- `OUTSIDE_COUNSEL.md`: Criteria for institutional legal partners.
- `WAVE_1_HIRING.md`: Hiring mandates and sequence.
- `REPO_BOUNDARY_CONTRACT.md`: (Pointer to `docs/REPO_BOUNDARY_CONTRACT_V1.md`).

## 2. Mirror Policy
- Documents in other repositories (e.g., `conxian-business`) are considered **mirrors** or **operational implementation drafts**.
- In the event of a conflict, the versions in this `.github-private` directory take precedence.
