## 2. Monthly Governance Rhythm

- **Week 1**: Refresh KPI values from source systems and verify data quality.
- **Week 2**: Run Root-to-Leaf governance review with engineering/product/security owners.
- **Week 3**: Update linked delivery issues/epics with approved action items.
- **Week 4**: Publish monthly scorecard snapshot and risk/decision summary.
